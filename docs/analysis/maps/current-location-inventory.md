# Current location inventory

De canonieke, genummerde inventaris staat in [01-current-location-inventory.md](./01-current-location-inventory.md).

Dit compatibiliteitspad bestaat omdat de onderzoeksopdracht zowel `current-location-inventory.md` als de verplichte genummerde output `01-current-location-inventory.md` noemt. Inhoud wordt niet gedupliceerd, zodat één bron van waarheid behouden blijft.
