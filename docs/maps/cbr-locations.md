# CBR-locatiecatalogus

CBR-locaties zijn een afzonderlijke, versieerbare catalogus. Een record bevat bron, bronverwijzing, geldigheidsperiode, reviewstatus en reviewer. Tenantbeheerders kunnen een kandidaat voorstellen; alleen een bevoegde catalogusbeheerder kan een gevalideerde versie publiceren.

NXTDrive claimt niet dat een door een tenant ingevoerd adres een officiële CBR-bron is. Bron- en gebruiksrechten moeten aantoonbaar zijn voordat `published` wordt toegestaan.

Examenplanning gebruikt een immutable vertrekstop. Reistijd naar de examenlocatie is operationele ondersteuning, geen examenroutevoorspelling. De applicatie bouwt geen interne turn-by-turnnavigatie en slaat geen gereden examenroute op.
